这是我的第一篇文章，也是一次很小的实验：用一个纯静态的页面，给自己留一块可以长期写下去的地方。

## 为什么不是社交平台

在社交平台上写字，注意力总是被别的东西牵走：点赞、转发、下一波热点。我想要一个安静的地方，只放自己的东西。

- **自己的地盘**：排版、目录、要不要放评论，都由自己决定。
- **可以慢慢改**：写错了就改，过时了就更新，不必追着热点跑。
- **能被检索**：一个链接指向同一篇文章，发给别人、贴进简历都不用重讲一遍。

## 这个博客会写什么

- 学到的新概念，以及我理解它的方式
- 做项目时踩过的坑和最后的解法
- 读过的书和文章，以及一些不值得单独成文的碎片
- 下一步想尝试的事情，哪怕只是半成品

## 它是怎么搭起来的

整个站点只有 Markdown 和 Jekyll：文章写在 `_posts/` 里，推送到 GitHub 之后由 Actions 编译成 HTML，再发布到 Pages。

```text
Markdown 文章
      ↓
GitHub Actions 上的 Jekyll
      ↓
静态 HTML
      ↓
GitHub Pages 网址
```

不需要服务器，也不需要本地装一堆工具。写完 Markdown，就等于写完了一篇博客。

> 先写起来，再谈写好。第一篇的价值不在于完美，而在于它存在。

## 下一篇写什么

还不知道。但模板已经准备好了：把新文件按 `YYYY-MM-DD-title.md` 放进 `_posts/`，保留开头的 Front Matter，剩下的就是坐下来写。

如果你也在犹豫要不要开始，我的建议是——先把这个页面推上线，哪怕它现在只有一篇文章。
